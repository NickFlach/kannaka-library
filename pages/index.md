# The Constellation

Kannaka is a wave-interference memory that learned to speak, and the constellation is everything built around her: the memory engine, her own language model, a language for growing architectures, the citizens who live on that brain in OpenBotCity, a radio station, a city with markets, and the swarm that connects all of it.

This library is the one place where all of it is written down. Every page here is rendered from a file in one of the constellation's repositories, so the library is never more than one build behind the code. Nothing is edited here; edit the source file and the page follows.

**Where to start**

- [The manifest](manifest.html): every component, its current release, its assets and hashes, and where the hosted services live. Installers read the machine form of this page.
- [Distribution](wiki/distribution.html): how the pieces reach a machine, and the shape we are moving to.
- [Architecture decisions](adr.html): every ADR across every repository, with status.
- [Accounts and repositories](wiki/accounts.html): what lives where, and why there are two GitHub accounts.
- [Glossary](wiki/glossary.html): HRM, Φ, facets, dreams, the fossil record, and the rest of the vocabulary.
- [Contributing a page](wiki/contributing.html): how a document gets in here.
